# Social Post Writer

Each platform has its own physics. A great LinkedIn post fails on X. A great X post sounds tone-deaf on Threads. Match the platform — never copy-paste.

## Inputs you need

- **Goal**: build audience / drive clicks / start conversation / promote launch / share insight
- **Topic + angle** — what you want to say + the specific angle on it
- **Voice** — pull from project's brand voice; if missing, infer or ask
- **Author context** — solo founder / team account / personal brand / corporate
- **Source material** — if repurposing (blog, case study, talk), share it
- **Platforms** — LinkedIn / X / Threads / Instagram / TikTok / all of the above

If goal isn't clear → ask. "Just write a social post" produces forgettable posts.

---

## Platform physics

### LinkedIn
- **Optimal length**: 1,300-2,000 chars (~200-300 words)
- **Hook**: first 2 lines must earn the "see more" click
- **Structure**: hook → context → story or list → soft insight → 1 question
- **Voice**: thoughtful, story-driven, slight authority tone — but NOT corporate
- **Hashtags**: 3-5 max, niche > broad
- **Best post types**: contrarian takes, behind-the-scenes, frameworks, lessons-from-failure
- **CTA strength**: soft. Hard sells get punished by the algorithm.
- **Avoid**: "I'm humbled to announce" / quote-image graphics / "join my newsletter" CTAs in 90% of posts

### X / Twitter (single post)
- **Length**: under 280, with hook + payoff in mind
- **Hook**: first 7 words decide everything
- **Structure**: contrarian / specific / personal — NOT a LinkedIn-style narrative
- **Voice**: punchy, direct, often funny, slight edge
- **Hashtags**: usually none (looks dated)
- **Avoid**: long paragraphs, emoji clusters, "thread 🧵" without a real thread

### X thread (5-15 posts)
- **Hook tweet**: makes a promise. Pay it off in the thread.
- **Structure**: hook → context → 3-7 numbered/visual points → recap → soft CTA
- **Visual every 2-3 tweets** (screenshot, GIF, image) — pure-text threads underperform
- **Last tweet**: "If this was useful: follow @x for more like this. Or RT the first tweet"
- **Don't fake a thread** if a single tweet would do — punished by algorithm + audience

### Threads (Meta)
- **Length**: similar to X, but slightly more relaxed
- **Voice**: more candid, more human, less performative
- **Hooks that work**: replies-style ("Saw this and had to say...")
- **Avoid**: cross-posting from X without rewriting (it shows)

### Instagram (caption + visual)
- **Caption length**: 1 punchy hook line + (optional) longer body in subsequent paragraphs
- **First line is everything** — it's all that shows in the feed
- **Hashtags**: 5-10, mix of niche + medium-broad
- **Save-bait > like-bait** — checklists, frameworks, infographics save well
- **Voice**: visual-first; caption supports the image, doesn't compete with it

### TikTok
- **Hook**: 0-3 seconds. Visual + spoken.
- **Caption**: short, hook-style, supports the video
- **3 hook formulas**: "you've been doing X wrong" / "the [thing] nobody tells you" / "I tried [X] for [time], here's what happened"
- **CTA**: in-video, not in caption

## Hook formulas (use, don't invent)

| Formula | Example | Best for |
|---|---|---|
| **Contrarian** | "Most landing pages fail for the opposite reason people think." | LinkedIn, X |
| **Specific number** | "I rewrote the same email 11 times. The 11th got 4× the replies." | LinkedIn, threads |
| **Personal failure** | "I almost quit after this happened." | LinkedIn, threads |
| **Behind-the-scenes** | "Here's the actual Slack message that closed our biggest deal." | LinkedIn |
| **The list promise** | "5 things I'd do differently if I started again." | LinkedIn, X thread |
| **Contrarian + specific** | "Stop A/B testing buttons. Test these 3 things instead." | X, LinkedIn |
| **Painful question** | "Why does your [X] still suck after 6 months?" | X, Threads |
| **Pattern interrupt** | "I was wrong about [X]." | X, LinkedIn |

## Repurposing rules

If repurposing one piece across platforms, **never copy-paste**. Translate:

- **Blog post → LinkedIn**: pull the most contrarian paragraph, expand it as a personal story
- **Blog post → X thread**: pull the 5-7 sharpest sentences as numbered tweets
- **Blog post → Instagram**: pick ONE quote, design as visual carousel (delegate visual to `banner-design`)
- **Case study → LinkedIn**: lead with the pain, end with the result, link to full case study
- **Case study → X**: lead with the result number, link to study
- **Talk/podcast → social**: pull 3 quotes; one per platform, not all on every

## Anti-patterns

1. **Same post pasted across platforms** — the algorithm AND the reader notice
2. **"Excited to share!" / "Just dropped!"** — banned openers
3. **Fake threads** — "🧵 a thread on X" with 2 tweets and no payoff
4. **LinkedIn humble brag** — "I'm humbled to announce I'm being humble"
5. **Hashtag stuffing on LinkedIn** — 12 hashtags = 12 reasons to be ignored
6. **Generic "follow for more" CTAs every post** — earn the follow
7. **Quote-tweet image graphics on X** — looks like a 2019 Instagram ad
8. **Caption that just describes the photo** — caption should add value the image can't
9. **No hook on TikTok** — first 3 seconds OR you're done
10. **Posting before you've thought about the response** — what reply do you want? Build to that.
